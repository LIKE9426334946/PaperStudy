# 论文方法与实验分析

## 1. 论文信息

- 标题：Gradient-Based Learning Applied to Document Recognition
- 作者：Yann LeCun、Léon Bottou、Yoshua Bengio、Patrick Haffner
- 期刊：Proceedings of the IEEE, Vol. 86, No. 11
- 时间：1998 年 11 月
- 页码：2278-2324
- 本工程复现范围：第 II、III 节及附录 A-C 中与 LeNet-5/MNIST 有关的核心实验

论文还讨论了图变换网络、在线手写识别和支票识别。它们依赖当时的专用数据与完整工业系统，不属于本目录的孤立数字识别复现范围。

## 2. 背景与研究动机

传统模式识别系统通常把任务拆成固定的手工特征提取器和可训练分类器。系统上限很大程度取决于设计者能否人为找到对平移、形变和书写风格稳定的特征。图像像素维度高、空间邻域相关性强，直接使用全连接网络会产生大量参数，也没有内置的平移鲁棒性。

论文的核心主张是：应让可微模型直接从近似原始像素中学习特征，并通过梯度方法整体优化；必要的先验知识应主要进入网络结构，而不是写成脆弱的手工规则。

## 3. 论文解决的问题

在孤立手写数字实验中，论文需要同时解决：

1. 从 28x28/32x32 像素直接学习局部特征；
2. 控制参数数量，避免全连接网络随输入尺寸快速膨胀；
3. 对平移、缩放、挤压和剪切等形变保持鲁棒；
4. 让输出分数能够用于类别识别和拒识；
5. 在大规模、冗余训练集上稳定而高效地优化共享参数网络。

## 4. 核心创新点

1. **局部感受野**：每个单元只观察上一层的小邻域。
2. **权重共享**：同一特征图在所有空间位置复用卷积核。
3. **空间下采样**：逐层降低位置精度，同时提高特征图数量。
4. **C3 非完全连接**：用论文表 1 的连接表减少连接并打破特征图对称性。
5. **端到端特征学习**：卷积、下采样、全连接和 RBF 都进入统一可微流程。
6. **随机对角 Levenberg-Marquardt**：使用非负的对角 Gauss-Newton 曲率为每个参数设置步长。
7. **数据形变扩充**：使用平移、缩放、挤压和水平剪切提高泛化能力。

## 5. 整体框架与模型结构

输入为 32x32 单通道图像。MNIST 的 28x28 图像在四周补 2 个背景像素。模型一共包含七个含参数的层（不计输入）：

| 层 | 运算 | 输出形状 | 可训练参数 |
| --- | --- | --- | ---: |
| C1 | 1→6，5x5 卷积 | 6x28x28 | 156 |
| S2 | 2x2 求和、每图一组 scale/bias | 6x14x14 | 12 |
| C3 | 表 1 稀疏连接，5x5 卷积 | 16x10x10 | 1,516 |
| S4 | 2x2 求和、每图一组 scale/bias | 16x5x5 | 32 |
| C5 | 16→120，5x5 卷积 | 120x1x1 | 48,120 |
| F6 | 120→84 全连接 | 84 | 10,164 |
| Output | 10 个固定欧氏 RBF 原型 | 10 个惩罚值 | 0 |
| 合计 |  |  | **60,000** |

S2/S4 不是最大池化。每个输出先对非重叠 2x2 区域求和，再乘以该特征图的可训练系数、加可训练偏置，最后经过缩放双曲正切。

C3 的 16 个输出特征图分别连接：

| C3 图 | S2 输入图 |
| ---: | --- |
| 0-5 | (0,1,2)、(1,2,3)、(2,3,4)、(3,4,5)、(0,4,5)、(0,1,5) |
| 6-11 | (0,1,2,3)、(1,2,3,4)、(2,3,4,5)、(0,3,4,5)、(0,1,4,5)、(0,1,2,5) |
| 12-14 | (0,1,3,4)、(1,2,4,5)、(0,2,3,5) |
| 15 | (0,1,2,3,4,5) |

## 6. 数学公式与代码对应关系

### 6.1 缩放双曲正切

论文式 (5)-(6)：

\[
x_i=f(a_i), \qquad f(a)=A\tanh(Sa)
\]

其中 \(A=1.7159\)、\(S=2/3\)。代码对应 models/layers.py 中的 ScaledTanh。

### 6.2 卷积与共享参数

对输出图 \(k\) 的位置 \((u,v)\)：

\[
a_{k,u,v}=b_k+\sum_{c\in\mathcal C_k}\sum_{i=0}^{4}\sum_{j=0}^{4}
w_{k,c,i,j}x_{c,u+i,v+j}
\]

其中 \(\mathcal C_k\) 是 C3 表 1 指定的输入图集合。C1/C5 使用普通 Conv2d，C3 由 SparseC3Convolution 按连接表逐图计算。

### 6.3 可训练下采样

\[
s_{k,u,v}=f\left(
\alpha_k\sum_{i=0}^{1}\sum_{j=0}^{1}
x_{k,2u+i,2v+j}+b_k
\right)
\]

代码对应 TrainableSubsampling。实现先进行平均池化再乘 4，以得到论文描述的四像素求和。

### 6.4 RBF 输出

论文式 (7)：

\[
y_i=\sum_j(x_j-w_{ij})^2
\]

F6 的 84 维输出与第 \(i\) 类固定的 7x12、取值为 ±1 的手写字符原型比较。惩罚越小越匹配，推理时取 argmin。代码对应 models/rbf.py 中的 EuclideanRBF。

### 6.5 训练损失

论文式 (8) 的正确类别 RBF 惩罚：

\[
E(W)=\frac{1}{P}\sum_{p=1}^{P} y_{D^p}(Z^p,W)
\]

对应 RBFMSELoss，也是论文配置的默认损失。

论文式 (9) 的判别式 MAP 准则：

\[
E(W)=\frac{1}{P}\sum_p
\left[
y_{D^p}+
\log\left(e^{-j}+\sum_i e^{-y_i}\right)
\right]
\]

对应 MAPDiscriminativeLoss。\(j\) 的实验取值未在论文中明确给出，因此它是配置项，不能声称默认值 10 来自原文。

### 6.6 初始化

附录 A 使用：

\[
w\sim U\left(-\frac{2.4}{F_i},\frac{2.4}{F_i}\right)
\]

其中 \(F_i\) 为单元 fan-in。代码对应 initialize_paper_uniform。

### 6.7 随机对角 Levenberg-Marquardt

附录 C 的逐样本更新可写为：

\[
w_k\leftarrow w_k-
\frac{\eta_{global}}{\mu+h_{kk}}
\frac{\partial E_p}{\partial w_k}
\]

论文令 \(\mu=0.02\)，每轮前在 500 个样本上重新估计非负对角 Gauss-Newton 曲率。

对式 (8)，损失关于 F6 状态的 Hessian 恰为 \(2I\)。令 \(J\) 为 F6 关于全部参数的 Jacobian，则：

\[
\operatorname{diag}(G)=2\operatorname{diag}(J^T J)
\]

optim/dlm.py 的 exact 模式直接计算这一数学等价的对角量；hutchinson 模式是便于快速验证的无偏随机估计，不能当作论文严格设置。

## 7. 训练流程

1. 下载 MNIST 60,000 个训练样本。
2. 将像素从 [0,1] 映射为背景 -0.1、前景 1.175，并补成 32x32。
3. 论文形变实验构造 60,000 原图 + 540,000 形变图的 600,000 虚拟集合。
4. 固定随机排列虚拟集合，每轮取连续 60,000 个；10 轮覆盖一遍，20 轮覆盖两遍。
5. 每轮开始前用 500 个样本估计对角曲率。
6. 按固定随机顺序逐样本前向、反向并立即更新参数。
7. 每轮在 10,000 个测试样本上计算错误率。
8. 保存 latest.pth、最佳错误率的 best.pth 和 JSONL 指标。

论文的全局学习率为：

| 训练轮次（从 1 开始） | 全局学习率 |
| --- | ---: |
| 1-2 | 0.0005 |
| 3-5 | 0.0002 |
| 6-8 | 0.0001 |
| 9-12 | 0.00005 |
| 13-20 | 0.00001 |

## 8. 推理流程

1. 对测试图像补边并按论文范围归一化；
2. 顺序经过 C1-S2-C3-S4-C5-F6；
3. 计算 F6 与十个固定 RBF 原型的平方欧氏距离；
4. 距离最小的原型类别作为预测；
5. 汇总准确率、错误率和 10x10 混淆矩阵。

## 9. 原论文实验设置

- 训练集：MNIST 60,000；
- 测试集：MNIST 10,000；
- 训练长度：20 次、每次 60,000 个样本；
- 优化：逐样本随机对角 Levenberg-Marquardt；
- 曲率：每轮前在 500 个样本上重新估计；
- \(\mu=0.02\)；
- 无形变测试错误率：约 0.95%；
- 有形变训练测试错误率：约 0.8%（图 8 展示 82 个错误样本）；
- 第 19 轮训练错误率：约 0.35%；
- 原硬件：单颗 200 MHz MIPS R10000 的 SGI Origin 2000；
- 原训练时间：约 2-3 个 CPU 日。

## 10. 数据集

MNIST 由 NIST Special Database 1 和 3 重组而成。原始二值数字保持长宽比缩放到 20x20，经过抗锯齿产生灰度，再按质心放到 28x28 区域。论文有时把 28x28 外扩到 32x32。

本工程通过 torchvision.datasets.MNIST 获取标准 60,000/10,000 划分。训练和测试都使用相同的 28→32 补边与数值映射；只对训练集启用形变。

## 11. 评价指标

- **Accuracy**：预测正确数 / 样本总数；
- **Error rate**：\(1-\text{Accuracy}\)，论文主要报告此指标；
- **Confusion matrix**：行是真实类别，列是预测类别；
- **Loss**：式 (8) 或式 (9) 的样本均值。

## 12. 无法从论文唯一确定的细节

复现必须把“原文明确值”和“工程选择”分开：

1. 论文列出了四类随机形变，但没有给出采样范围。本工程将平移 2 px、尺度 ±15%、挤压 ±15%、水平剪切 ±15° 作为公开可改的默认值。
2. 十个 RBF 数字原型只以低分辨率图 3 发布，没有机器可读权重。本工程用显式 12x7 字符模板转录其构造原则，保证固定、可检查和可替换，但不声称逐像素等同原始私有代码。
3. 式 (9) 中正数 \(j\) 未报告具体实验值，配置默认 10 只是可运行选择。
4. PyTorch 的算子顺序、浮点实现与 1998 年代码不同，因此即使超参数相同也不保证逐步数值一致。

这些差异都被限制在配置或独立模块中，不会悄悄替换论文结构。
