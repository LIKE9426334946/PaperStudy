## 论文信息

- **作者**：Yann LeCun, Léon Bottou, Yoshua Bengio, Patrick Haffner
- **发表期刊**：Proceedings of the IEEE, Vol. 86, No. 11, pp. 2278–2324
- **年份**：1998
- **论文链接**：[IEEE Xplore](https://ieeexplore.ieee.org/document/726791) ｜ [DOI: 10.1109/5.726791](https://doi.org/10.1109/5.726791)

> LeNet-5 只是这篇长论文的一部分。论文还讨论了梯度学习、文档识别、图变换网络（GTN）、支票识别等内容。本目录重点复现论文第 II-B 节的 LeNet-5。

## 论文简介

论文的核心观点是：与依赖人工设计特征和大量启发式规则的传统文档识别系统相比，可以构造一个由可微模块组成的系统，直接通过梯度下降共同学习特征提取和分类。LeNet-5 是其中用于手写数字识别的卷积神经网络。

LeNet-5 将三个重要思想组合到了一起：

1. **局部感受野**：一个神经元只观察输入中的局部区域。
2. **权重共享**：同一特征图在不同空间位置复用同一个卷积核。
3. **空间下采样**：降低特征图分辨率，使表示对小幅位移和形变更稳定。

## 核心思想

### 1. 卷积学习局部特征

对于输入特征图 $x$，卷积层的一个输出位置可以写为：

$$
a_{k,h,w}=b_k+\sum_c\sum_{u=0}^{K-1}\sum_{v=0}^{K-1}
W_{k,c,u,v}\,x_{c,h+u,w+v}
$$

代码中的 `nn.Conv2d` 完成局部乘加和权重共享，之后再使用论文的非线性函数。

### 2. 论文使用的 squashing function

论文采用缩放的双曲正切函数：

$$
f(a)=A\tanh(Sa),\qquad A=1.7159,\quad S=\frac{2}{3}
$$

对应 `blocks.py` 中的：

```python
1.7159 * torch.tanh((2.0 / 3.0) * x)
```

它是论文所称的 sigmoid squashing function，不是现代 LeNet 教程中常见的 ReLU。

### 3. 带参数的下采样

S2 和 S4 不是普通的无参数平均池化。每个输出单元先求对应 $2\times2$ 区域之和，再乘以该特征图自己的可学习系数，并加上可学习偏置：

$$
s_{c,h,w}=f\left(
\alpha_c\sum_{u=0}^{1}\sum_{v=0}^{1}x_{c,2h+u,2w+v}+\beta_c
\right)
$$

每个通道拥有一个 $\alpha_c$ 和一个 $\beta_c$，所以 S2 有 $6\times2=12$ 个参数，S4 有 $16\times2=32$ 个参数。

### 4. C3 的稀疏连接

C3 并不让 16 个输出特征图全部连接 S2 的 6 个输入特征图。论文这样设计有两个目的：减少计算量，并打破不同特征图之间的对称性，让它们学习互补特征。

| C3 输出图 | 连接的 S2 输入图 |
| ---: | :--- |
| 0 | 0, 1, 2 |
| 1 | 1, 2, 3 |
| 2 | 2, 3, 4 |
| 3 | 3, 4, 5 |
| 4 | 0, 4, 5 |
| 5 | 0, 1, 5 |
| 6 | 0, 1, 2, 3 |
| 7 | 1, 2, 3, 4 |
| 8 | 2, 3, 4, 5 |
| 9 | 0, 3, 4, 5 |
| 10 | 0, 1, 4, 5 |
| 11 | 0, 1, 2, 5 |
| 12 | 0, 1, 3, 4 |
| 13 | 1, 2, 4, 5 |
| 14 | 0, 2, 3, 5 |
| 15 | 0, 1, 2, 3, 4, 5 |

一共有 60 组“输入特征图 → 输出特征图”连接，因此参数量为：

$$
60\times5\times5+16=1516
$$

实现没有简单地创建一个完整的 `Conv2d(6, 16, 5)` 再屏蔽权重，而是为每个输出图创建只接收指定输入图的卷积。这样未连接的权重根本不存在，C3 的可训练参数量与论文完全一致。

### 5. 欧氏 RBF 输出层

F6 有 84 个单元，因为 $84=7\times12$，可以把它看成一张 $7\times12$ 的字符图案。第 $i$ 个输出单元保存第 $i$ 类的固定字符模板 $w_i$，并计算平方欧氏距离：

$$
y_i=\sum_{j=0}^{83}(x_j-w_{ij})^2
$$

这里 $y_i$ 是**能量/距离**：值越小，F6 表示与第 $i$ 类模板越接近。因此预测规则是：

$$
\hat c=\arg\min_i y_i
$$

这与现代分类器输出“值越大越可信”的 logits 正好相反，不能直接对这些输出使用 `argmax`。

### 6. MAP 训练准则

论文第（9）式的损失为：

$$
E(W)=\frac{1}{P}\sum_{p=1}^{P}\left[
y_{D^p}(Z^p,W)+
\log\left(e^{-J}+\sum_i e^{-y_i(Z^p,W)}\right)
\right]
$$

- 第一项降低正确类别的 RBF 距离。
- 第二项避免所有输出能量一起坍缩到很小的值，并推动错误类别的能量升高。
- $J$ 是论文引入的正数常量，属于训练配置，因此 `LeNet5MAPLoss` 要求调用者显式传入。
- 实现使用 `torch.logsumexp` 计算对数项，数学上等价但数值更稳定。

## 模型整体结构

LeNet-5 接收居中的 $32\times32$ 单通道图像。原始 MNIST 是 $28\times28$，需要在数据预处理阶段放入 $32\times32$ 画布；这不属于模型 forward 的核心计算，因此未放进网络内部。

| 层 | 核心运算 | 输出形状（省略 B） | 可训练参数 |
| :--- | :--- | :--- | ---: |
| Input | 灰度图像 | `[1, 32, 32]` | 0 |
| C1 | `Conv2d(1, 6, 5)` + scaled tanh | `[6, 28, 28]` | 156 |
| S2 | $2\times2$ 求和、通道缩放/偏置 + scaled tanh | `[6, 14, 14]` | 12 |
| C3 | 16 个稀疏连接的 $5\times5$ 卷积 + scaled tanh | `[16, 10, 10]` | 1,516 |
| S4 | $2\times2$ 求和、通道缩放/偏置 + scaled tanh | `[16, 5, 5]` | 32 |
| C5 | `Conv2d(16, 120, 5)` + scaled tanh | `[120, 1, 1]` | 48,120 |
| F6 | `Linear(120, 84)` + scaled tanh | `[84]` | 10,164 |
| Output | 10 个固定模板的平方欧氏距离 | `[10]` | 0（840 个固定值） |
| **合计** |  |  | **60,000** |

C5 虽然使用卷积实现，但输入空间尺寸恰好为 $5\times5$，卷积核也为 $5\times5$，所以每个输出单元都会观察 S4 的全部 400 个单元。对于固定的 $32\times32$ 输入，它在连接关系上等价于全连接层；如果输入尺寸变大，C5 才会重新表现出卷积层的空间特性。

## Forward 数据流

给定 `x: [B, 1, 32, 32]`：

1. `C1` 用 6 个 $5\times5$ 卷积核提取初级局部特征，得到 `[B, 6, 28, 28]`。
2. `S2` 对每个通道执行带可学习系数和偏置的下采样，得到 `[B, 6, 14, 14]`。
3. `C3` 按论文连接表选取输入特征图并执行卷积，拼成 `[B, 16, 10, 10]`。
4. `S4` 再次下采样，得到 `[B, 16, 5, 5]`。
5. `C5` 的感受野覆盖整个 S4，得到 `[B, 120, 1, 1]`。
6. `flatten(start_dim=1)` 只展平通道和空间维，保留 batch 维，得到 `[B, 120]`。
7. `F6` 映射为 84 维字符表示，得到 `[B, 84]`。
8. RBF 层通过广播构造 `[B, 10, 84]` 的差值，沿最后一维平方求和，得到 `[B, 10]` 的类别能量。

调用 `forward(..., return_intermediates=True)` 可以同时取得 C1、S2、C3、S4、C5、F6 的中间 Tensor，方便逐层学习和检查形状。

## 每个代码模块的作用

### `ScaledTanh`

直接实现论文的 $1.7159\tanh(2x/3)$，不把它替换为 ReLU。

### `TrainableSubsampling2d`

展开 S2/S4 的“局部求和 → 通道缩放 → 通道偏置”过程。激活函数留在主模型中调用，使 forward 数据流更清晰。

### `SparseC3Convolution`

根据 Table I 对输入通道分组；每个输出特征图使用一个独立的真实 `nn.Conv2d`，最后通过 `torch.cat` 拼接 16 个输出图。

### `EuclideanRBF`

使用 `register_buffer` 保存固定模板，使模板能跟随模型移动到 CPU/GPU、能进入 `state_dict`，但不会被优化器更新。

### `LeNet5MAPLoss`

将论文第（9）式翻译为 `gather`、`cat` 和 `logsumexp` 等真实 PyTorch 运算。

### `LeNet5`

按照 C1 → S2 → C3 → S4 → C5 → F6 → RBF 的顺序组合全部模块，并明确返回 RBF energies。

## 与常见“简化版 LeNet”及现代 CNN 的区别

| 原论文 LeNet-5 | 常见教程/现代实现 |
| :--- | :--- |
| C3 采用指定的部分连接 | 通常直接使用完整 `Conv2d(6, 16, 5)` |
| 下采样层具有可学习缩放和偏置 | 常用无参数 `AvgPool2d` 或 `MaxPool2d` |
| 使用 scaled tanh | 常用 ReLU、GELU 等 |
| C5 保持卷积形式 | 常被直接写成展平后的全连接层 |
| 末层输出到固定字符模板的距离 | 常用可训练 `Linear(84, 10)` + softmax |
| 预测使用 `argmin` | logits 通常使用 `argmax` |
| 输入是居中的 $32\times32$ 图像 | 教程常直接输入 $28\times28$ MNIST |
| 无 BatchNorm、Dropout、残差连接 | 现代网络通常加入更多稳定训练的结构 |

## 论文明确内容与合理补全

为了避免把现代工程习惯误写成论文结论，本实现区分了以下两类内容。

### 论文明确描述并保留的内容

- 七个有参数层及其尺寸；
- scaled tanh；
- S2/S4 的可学习系数和偏置；
- C3 的连接表；
- C5 的卷积形式；
- 84 维 F6；
- 固定 $\pm1$ 字符模板、欧氏 RBF 输出和 `argmin` 决策；
- 第（9）式 MAP 损失。

### PyTorch 实现中的合理补全

- 论文中的 RBF 字符模板以图片展示，没有给出可直接复制的数字矩阵。`make_digit_rbf_centers()` 提供了可读的 $12\times7$ 数字栅格重建，并明确允许调用者传入从原图精确提取的 `[10, 84]` 模板；不把该重建冒充成论文逐像素原始数据。
- 下采样系数初始化为 $1/4$、偏置初始化为 0，使网络初始时等价于平均池化；这是工程初始化选择，论文只规定它们需要学习。
- 普通卷积和线性层保留 PyTorch 默认初始化。初始化、优化器和训练循环不属于本次模型核心复现。
- forward 对输入尺寸进行检查，避免 C5 因错误尺寸不再输出 $1\times1$；这是便于学习和调试的保护逻辑。

## 使用示例

```python
import torch

from LeNet5 import LeNet5, LeNet5MAPLoss

model = LeNet5()
x = torch.randn(4, 1, 32, 32)
targets = torch.tensor([0, 1, 2, 3])

energies, features = model(x, return_intermediates=True)
predictions = energies.argmin(dim=1)

criterion = LeNet5MAPLoss(junk_energy=40.0)
loss = criterion(energies, targets)
loss.backward()

print(energies.shape)       # torch.Size([4, 10])
print(features["C3"].shape) # torch.Size([4, 16, 10, 10])
```

这里的 `junk_energy=40.0` 只是调用示例中的训练超参数，不代表论文为所有实验规定了固定值。

## 阅读心得

LeNet-5 的价值不只是“网络很小”，而是它已经清楚展示了现代 CNN 的基本设计语言：局部连接、共享参数、层级特征和端到端学习。最值得注意的是，今天教材里常见的 LeNet 通常经过了显著简化。只有阅读原论文，才会看到 C3 的非对称稀疏连接、池化层的可训练参数和 RBF 能量分类器。

从学习角度看，这个模型也很好地说明了“架构”和“实现惯例”应当分开：`Conv2d + AvgPool + ReLU + Linear` 可以完成一个现代数字分类器，但它并不等于 1998 年论文中完整的 LeNet-5。
